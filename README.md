# المدار تجربة

نسخة تجربة من تطبيق مكتبة المدار لهواتف أندرويد.

**التحميل:** [madar-test.apk](https://github.com/madarlibrary/madar-app-download/releases/latest/download/madar-test.apk)

بعد التنزيل افتح الملف، ووافق على التثبيت من مصادر غير معروفة إذا طلب الهاتف ذلك.
الملف `host.txt` يخبر التطبيق بعنوان سيرفر التجربة الحالي.
